🚀 NovaStack | Modern IT Solutions Landing Page
NovaStack is a high-performance, responsive landing page designed for a modern IT Startup. This project was developed as an internship task to demonstrate expertise in UI/UX design, responsive layouts, and modern front-end development workflows.

🔗 Live Demo
View the Project: https://s-qrock-web-task1.vercel.app/

✨ Features
Modern Tech Aesthetic: A sleek dark-themed UI using a custom color palette (techBlue and slateDark).

Fully Responsive: Optimized for all devices—from mobile handsets to large desktop monitors.

Interactive UI: Includes a sticky glassmorphism navbar, hover-animated feature cards, and scroll-triggered header effects.

Core Sections:

Hero Section: High-impact value proposition with clear Call-to-Action (CTA) buttons.

Features Grid: Highlights Cloud Infrastructure, Cybersecurity, and DevOps with modern SVG icons.

About Us: Concise company overview and strategic value points.

Contact & Footer: Professional lead generation form and social connectivity.

🛠️ Tech Stack
Core: HTML5, JavaScript (ES6+)

Styling: Tailwind CSS

Typography: Poppins via Google Fonts

Deployment: Vercel
